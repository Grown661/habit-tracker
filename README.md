# Habit Tracker

Gewohnheiten konsequent durchzuziehen scheitert oft daran, dass man den eigenen Fortschritt nicht sieht – dieser Tracker macht ihn als Jahres-Heatmap im GitHub-Stil sichtbar.

## Features

- Gewohnheiten anlegen und löschen
- Tägliches Abhaken per Checkbox
- Jahres-Heatmap: Farbe zeigt den Erfüllungsgrad über alle Gewohnheiten pro Tag
- Aktuelle Streak und längste Streak pro Gewohnheit
- Export und Import als JSON
- Daten bleiben lokal im Browser (localStorage)

## Stack

- HTML, CSS, Vanilla JavaScript
- Keine Abhängigkeiten, keine Build-Kette

## Setup & Start

`index.html` im Browser öffnen – fertig.
